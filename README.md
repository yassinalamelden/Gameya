## About

A *gam'eya* (also known as *tanda*, *susu* or *chit fund*) is a rotating savings circle: a group of people each contribute a fixed amount every cycle, and each cycle one member receives the whole pot.

Gameya brings these circles onto PayPal and uses AI to help run them.
